## ~/studies/paper  ·  Pre-Execution Ontology-Based Validation of LLM Tool Calls

### validation.graph — Ontology-Based Validation of LLM Tool Calls
paper, in progress · accept, then reject

### abstract.md — Abstract
A Knowledge Graph Approach to Hallucination Reduction

LLM agents invoke external tools from statistical knowledge frozen in their parameters, while the execution environment evolves — producing plausible but invalid calls: nonexistent tools, fabricated parameters, and violated preconditions. This work models the tool universe as a formal ontology materialized in a knowledge graph and uses it as a deterministic validation layer that checks every generated tool call against the semantic contract before execution. Experimental evaluation against an unvalidated baseline on established function-calling benchmarks measures hallucination reduction by error type, testing the hypothesis that symbolic validation excels precisely where neural reviewers are weakest: structural errors, with near-zero harmfulness.

### error-types.txt — What the layer catches
plausible but invalid calls, by type

- Nonexistent tools — does the tool exist in the ontology?
- Fabricated parameters — are the arguments part of its contract?
- Violated preconditions — do its requirements hold right now?

### evaluation.txt — Evaluation
validated agent vs. unvalidated baseline

Established function-calling benchmarks; hallucination reduction measured by error type.
